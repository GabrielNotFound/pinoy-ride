# CMAI Git Branches Standard

Standard naming convention should be implemented across all projects.

## Basic

Sample of branch pertain to specifc module

```bash
web
webapi
websignup
```

## Branches

All modules should have a corresponding master branch name convention

```bash
web-master
ios-master
android-google-master
android-huawei-master
```

## Tags

Convention should have comply with project name together with version number. Tracking of version refer to version document control.

```bash
ios-1.1001.1001
android-google-1.1001.1001
android-huawei-1.1001.1001
```
